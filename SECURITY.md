# Security

Please do not publicly disclose a security vulnerability or post credentials, tokens, private user data, or exploit details in an issue.

Use GitHub's private vulnerability reporting for this repository when available. If private reporting is not enabled, open a minimal issue that requests a private contact channel without including sensitive details.

Include the affected file or feature, reproduction steps, impact, and proposed mitigation when they can be shared safely. Publicly disclose only after the issue has been assessed and a fix or mitigation is available.

Event Atlas is a static project with no server-side secrets or production backend. Reports involving supply-chain changes, browser security, or unsafe content handling are especially relevant.
