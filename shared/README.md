# Shared material

Use this directory for genuinely event-neutral components, layouts, styles, and utilities that are adopted by multiple annual event experiences. Keep one-off event behavior inside its annual event folder.

Directories are intentionally separated so future shared work remains easy to classify:

- `components/`: reusable UI behavior
- `layouts/`: page and presentation composition
- `styles/`: shared design primitives
- `utilities/`: event-neutral data and build helpers
