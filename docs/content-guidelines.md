# Content guidelines

## Classify every idea

- **Fact**: directly supported by an official or identified source
- **Analysis**: interpretation of sourced facts, with its reasoning visible
- **Illustration**: a deterministic or fictional demonstration, clearly labeled
- **Prediction**: an explicitly dated possibility, not an announced capability
- **Demo**: runnable local behavior with setup, limitations, and expected output

Do not present generated screenshots, simulated metrics, predictions, or illustrative interfaces as live product behavior.

## Source hierarchy

Prefer the event organizer's official announcement, documentation, repository, product page, or session recording. If a claim comes from another source, identify it beside the claim and preserve the URL.

## Accessibility

- Support keyboard navigation and visible focus.
- Provide useful alt text and labels.
- Do not rely on color alone.
- Honor reduced-motion preferences.
- Make mobile layouts readable without requiring a presentation-sized screen.

## Privacy and security

Never commit tokens, credentials, unpublished material, customer data, personal files, local paths, or private organization information. Do not copy proprietary event media into the repository without permission.
